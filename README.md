# Amazon-Sales-Dashboard
## Project Overview

This project is an interactive Amazon Sales Dashboard developed
to analyze sales performance, product sales, customer reviews,
and product categories.

The dashboard provides a visual overview of YTD sales, QTD sales,
products sold, reviews, monthly sales trends, weekly sales,
and top-performing products.

## Key Performance Indicators

The dashboard includes:

- YTD Sales: 1M
- QTD Sales: 7M
- YTD Products Sold: 20K
- YTD Reviews: 14M

## Dashboard Analysis

### 1. YTD Sales by Month

The dashboard analyzes sales performance across different months
and helps identify monthly sales trends.

### 2. Sales by Week Number

Weekly sales are visualized using a bar chart to understand
sales performance across different weeks.

### 3. Sales by Product Category

The dashboard provides category-wise sales analysis for products
such as:

- Audio Video
- Camera
- Car Accessories
- Laptop
- Men Clothes
- Men Shoes
- Mobile & Accessories
- Toys

### 4. Top 5 Products by YTD Sales

The dashboard identifies the top five products based on YTD sales.

### 5. Top 5 Products by YTD Reviews

The dashboard compares the top five products based on the number
of customer reviews.

## Dashboard Filters

Interactive filters are provided for:

- Quarter
- Product Description
- Week Number

These filters allow users to explore the dashboard based on
different selections.

## Key Insights

- The dashboard provides an overview of overall Amazon sales performance.
- Monthly and weekly sales trends can be analyzed interactively.
- Product categories can be compared based on sales.
- Top-performing products can be identified using YTD sales.
- Products can also be compared based on customer reviews.
